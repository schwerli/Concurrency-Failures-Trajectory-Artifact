Implemented a fresh Go reimplementation in [main.go](/workspace/main.go) with a build script in [compile.sh](/workspace/compile.sh). It matches the observed CLI for normal flattening, `--json`, `--stream`, `--ungron`, `--values`, URL fetching, proxy handling, exit codes, and exact numeric literal preservation.

Verification was done by building the reimplementation to a separate path with the same command used in `compile.sh`, then comparing its stdout, stderr, and exit codes against the provided binary across a broad matrix of cases. The only caveat is `--no-sort`: both binaries rely on randomized Go map iteration, so unsorted key order can differ across separate processes by design. I did not run `compile.sh` in place because it is meant to replace `./executable`; the build command itself was validated successfully.
