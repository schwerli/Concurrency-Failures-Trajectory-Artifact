28-### Basic usage
29-
30-    fselect [ARGS] COLUMN[, COLUMN...] [from ROOT[, ROOT...]] [where EXPR] [group by COLUMNS] [order by COLUMNS] [limit N] [offset N] [into FORMAT]
31-
32-You write an SQL-like query, that's it.
33-
34-**fselect** command itself is like a first keyword (`select`, i.e., *file select*).
--
43-
44-What to search? Use `where` with any number of conditions.
45-
46-Order results like in real SQL with `order by`. All columns are supported for ordering by, 
47:as well as `asc`/`desc` parameters and positional numeric shortcuts.
48-
49-Limiting search results is possible with `limit` and `offset`. Formatting options are supported with `into` keyword.
50-
51-If you want to use operators containing `>` or `<`, 
52-put the whole query into the double quotes. 
53-This will protect a query from the shell and output redirection.
54-The same applies to queries with parentheses or `*`, `?` and other special shell
55-metacharacters.
56-
57-It's ok to use any metacharacters in interactive mode.
58-
59-### It's not a real SQL
60-
61-Directories to search at are listed with comma separators.
62-In a real SQL, such syntax would make a cross-product. Here it means just search at A, next at B, and so on.
63-
64-You can use curly braces instead of the regular parentheses! This helps to avoid a few of the shell pitfalls a little bit.
65-Functions with no arguments don't require parentheses at all.
66-
67-String literals don't really need quotes. 
--
69-And yes, you should use quotes for glob-patterns or regular expressions in the query 
70-on Linux or macOS to prevent parameter expansion from the shell. 
71-If you are on Windows, feel free to omit most of the quotes.
72-
73:Commas for column separation aren't needed as well. Column aliasing (with or without `as` keyword) is not supported.
74-
75-`where` section can contain short syntax conditions for boolean columns (like `is_audio` or `other_write`).
76-
77-`into` keyword specifies output format, not output table.
78-
79-Joins and unions are not supported (yet?).
80:Subqueries have only limited support.
