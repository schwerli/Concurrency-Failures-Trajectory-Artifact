Implemented a clean-room Go reimplementation in [main.go](/workspace/main.go), with a minimal module file in [go.mod](/workspace/go.mod) and a build script in [compile.sh](/workspace/compile.sh) that produces `./executable`.

Before replacing the provided binary, I compared the new implementation against it across 67 observed cases covering help/version/error text, stdin replacements, regex and fixed-string modes, capture expansion rules, flag quirks, empty-pattern behavior, preview formatting, in-place file edits, and failure cases without partial writes. I then ran `./compile.sh`, which rebuilt `./executable`, and smoke-tested the rebuilt binary in place.
