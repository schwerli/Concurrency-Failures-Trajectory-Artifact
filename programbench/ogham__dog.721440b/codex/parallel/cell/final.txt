Implemented a stdlib-only Go reimplementation in [main.go](/workspace/main.go) with [compile.sh](/workspace/compile.sh) building it to `./executable`. It covers the observed CLI surface and behavior: help/version, option parsing and error codes, query expansion, system-resolver fallback, UDP/TCP/TLS/HTTPS transports, EDNS/`--txid`/`-Z` tweaks, text output, short mode, JSON output, and truncation fallback.

I rebuilt `./executable` from that source and smoke-tested it against controlled localhost DNS responders for normal answers, authorities/additionals, status lines, JSON shape, and network/CLI error paths. Outbound DNS/network from this container was unavailable, so live external DoT/DoH/TLS wasn’t end-to-end verified here. The active build path is the Go code; any stray Python files in the workspace are not used by `compile.sh`.
