A clean-room reimplementation is in place in [Main.java](/workspace/src/Main.java) with a build wrapper in [compile.sh](/workspace/compile.sh). `./compile.sh` now regenerates `./executable` as a launcher for the new Java source; it does not invoke or depend on the provided binary.

Verified against the observed behavior on representative cases:
- CLI usage, parse errors, and the odd bare `--help` / bare `-h` wrapper behavior
- Default and explicit output naming, including `_2` suffixing for implicit PNG targets
- PNG and SVG rendering for boxes, document/storage/ellipse/decision/trapezoid/manual-op/io shapes, arrows, dashed lines, bullets, point markers, shadows, transparency, background color, scaling, verbose/debug mode
- HTML mode output naming, image directory layout, and overwrite checks

I did not exhaustively prove pixel-perfect identity for every possible ASCII diagram, but the implementation matches the sampled binary behavior closely on the cases I black-boxed.
