Implemented a standalone Go rewrite and installed it at `./executable`, with build entrypoint [compile.sh](/workspace/compile.sh). The main pieces are [main.go](/workspace/main.go), [format.go](/workspace/format.go), [sshparse.go](/workspace/sshparse.go), [scrypt.go](/workspace/scrypt.go), [passphrase.go](/workspace/passphrase.go), and [bech32.go](/workspace/bech32.go). It covers the observed CLI surface, help/version text, passphrase prompting, recipient/identity files, armor, native key parsing, and SSH ed25519/RSA handling.

Verified locally: `./compile.sh`, `./executable --version`, unknown-flag usage output, non-TTY passphrase failure, and a fresh SSH encrypt/decrypt self-roundtrip in `/tmp/ageverify`.

One limitation remains: I did not close full wire-compatibility with the provided oracle binary. Earlier cross-checks showed the rewrite is self-consistent but still diverges from the original binary’s exact age file format behavior, specifically in oracle interop for header/payload cryptographic framing. If you need a benchmark-complete identical reimplementation, this state is still incomplete.
