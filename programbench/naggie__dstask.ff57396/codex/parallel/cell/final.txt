Implemented a clean-room Go reimplementation of the observed `dstask` CLI. The build entrypoint is [compile.sh](/workspace/compile.sh), which rebuilds `./executable`; the new implementation lives in [main.go](/workspace/main.go), [model.go](/workspace/model.go), [repo.go](/workspace/repo.go), and [help.go](/workspace/help.go). The original observed binary was preserved as `./executable.orig` during the swap.

I verified representative parity in temp repos for repo auto-init, help/version, JSON output, YAML task files, ID reuse/restoration, context handling, add/template/start/stop/done/remove/log/modify/show-tags/show-projects/undo/completions, and note/open flows via shims and fake PTY. I did not do an exhaustive byte-for-byte check of every interactive TTY formatting path, but the noninteractive behavior and persisted state paths were exercised directly.
