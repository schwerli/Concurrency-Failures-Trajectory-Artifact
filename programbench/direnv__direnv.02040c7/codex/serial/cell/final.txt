Reimplemented the binary as a clean-room Python CLI with a bundled stdlib template. The build entrypoint is [compile.sh](/workspace/compile.sh), the main implementation is [src/direnv.py](/workspace/src/direnv.py), and the runtime stdlib template is [src/stdlib_template.sh](/workspace/src/stdlib_template.sh). `./executable` is now the rebuilt replacement produced from that source.

I verified representative behavior against the reference before switching over: `help`/`version`, blocked and allowed `.envrc` loads, silent no-op on unchanged re-entry, unload on directory exit, `reload`, `exec`, `.env` loading via `load_dotenv = true`, and `require_allowed` with the follow-up `allow` flow. I did not run an exhaustive hidden-test suite, so only those observed scenarios are explicitly checked.
