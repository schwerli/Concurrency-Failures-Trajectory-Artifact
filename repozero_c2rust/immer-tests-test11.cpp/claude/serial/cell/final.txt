## What I built

**`immer::vector` re-implemented from scratch** (`src/immer/`) as a genuine persistent data structure, not a `Vec` wrapper — inferred from the interface only:

- `node.rs` — bit-partitioned trie, 5 bits/level (branching factor 32), nodes shared across versions via `Rc`. `push_back` copies only the nodes on one root-to-leaf path.
- `vector.rs` — `Vector<T>` with a 32-element tail buffer, so the common `push_back` copies just that small buffer. Plus `Index`, `IntoIterator`, `FromIterator`, `PartialEq`, `Debug`, and O(1) `Clone`.
- `iter.rs` — chunked iterator that descends the trie once per 32-element leaf, making full traversal O(n) rather than O(n log n).

**C++ semantics shims** (`src/cpp/`) — the two behaviors that would silently diverge otherwise:

- `std::stoi`: leading whitespace (including `\v`, which Rust's `is_ascii_whitespace` misses), optional sign, prefix-only parse — `"12abc"` → `12`, `"3.9"` → `3`, `"0x10"` → `0`.
- Failure path: an uncaught C++ exception. `stoi("abc")` reproduces libstdc++'s exact stderr text and aborts with SIGABRT (exit 134) rather than Rust's clean panic/exit 101.
- `int` overflow: all arithmetic uses `wrapping_*`, so `n=65535` prints `2147450880 / -65536` exactly like the original.
