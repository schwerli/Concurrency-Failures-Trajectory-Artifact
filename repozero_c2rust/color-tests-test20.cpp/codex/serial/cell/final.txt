Implemented the Rust port as a complete Cargo project in [Cargo.toml](/output/Cargo.toml), with the root entry at [test20.rs](/output/test20.rs) and library code in [converter.rs](/output/src/converter.rs), [models.rs](/output/src/models.rs), and [formatting.rs](/output/src/formatting.rs). It uses only `std`, parses positional args in the same triplet pattern as the C++ binary, keeps the computations in `f32`, and includes a custom float formatter to match `std::cout` output.

Compilation succeeded with `cargo build --release`, and I also produced a standalone executable at `/output/test20`. I diffed the Rust output against `/workspace/dataset/test20_executable` on the default run and several additional cases, including scientific-notation output and incomplete trailing args, and the checked outputs matched byte-for-byte.
