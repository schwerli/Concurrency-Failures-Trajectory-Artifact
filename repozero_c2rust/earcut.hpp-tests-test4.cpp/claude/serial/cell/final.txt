## Key porting decisions

- **Pointers → arena indices.** The C++ `Node*` graph became a `Vec<Node>` with `usize` links. Nodes are never freed mid-run, so indices behave exactly like the original pointers — including identity comparisons like `p != ear->prev`, which the algorithm depends on.
- **Float semantics preserved.** `fmin`/`fmax` replicate `std::min<double>`/`std::max<double>` tie-breaking rather than using `f64::min` (which differs on NaN/±0). Expression operand order in `area`, `point_in_triangle` and the bridge-finding interpolation is kept verbatim so rounding is identical.
- **Subtle details that mattered:** in `find_hole_bridge`, `mx`/`my` are snapshotted before the scan loop while `m->x` inside the comparison tracks the *current* `m`; in `cure_local_intersections`, `p->next` is read after the first `remove_node`; the `threshold`-based early exit decides `hashing` (kicks in at n ≥ 21, exercising the z-order code path).
- **`atoi` reimplemented** — leading whitespace, optional sign, stop at first non-digit, `0` on garbage.
- **Output** uses `write!(…, "{} ", idx)` — trailing space, no newline, matching `std::cout` exactly (confirmed with `xxd`).
