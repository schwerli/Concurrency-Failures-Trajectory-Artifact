**Library Files**
The implementation wired by [test5.mjs](/output/test5.mjs) is split across these `.mjs` modules in `/output`:

- [lib/cli/spec.mjs](/output/lib/cli/spec.mjs) for the option spec plus exact usage/help/error text.
- [lib/cli/parser.mjs](/output/lib/cli/parser.mjs) for manual `process.argv` parsing with argparse-like behavior, required `int` validation, `--help`, `--help=...`, `--`, duplicate flags, and underscore-containing integers.
- [lib/graph/digraph.mjs](/output/lib/graph/digraph.mjs) for a minimal directed graph implementation.
- [lib/graph/dag.mjs](/output/lib/graph/dag.mjs) for directed-acyclic-graph detection.
- [lib/format/python.mjs](/output/lib/format/python.mjs) for Python-style boolean formatting (`True` / `False`).
- [lib/index.mjs](/output/lib/index.mjs) for local ESM re-exports.

**Entry File**
[test5.mjs](/output/test5.mjs)

```js
import {
  DiGraph,
  formatPythonBool,
  getProgramName,
  isDirectedAcyclicGraph,
  parseTest5Arguments,
} from './lib/index.mjs';

const programName = getProgramName(process.argv[1]);
const parsedArguments = parseTest5Arguments(process.argv.slice(2), programName);

if (parsedArguments.kind === 'help') {
  process.stdout.write(parsedArguments.text);
  process.exit(0);
}

if (parsedArguments.kind === 'error') {
  process.stderr.write(parsedArguments.text);
  process.exit(parsedArguments.code);
}

const { a, b, c, d, e } = parsedArguments.values;
const graph = new DiGraph();

graph.addEdgesFrom([
  [a, b],
  [b, c],
  [c, d],
  [d, e],
]);

process.stdout.write(`${formatPythonBool(isDirectedAcyclicGraph(graph))}\n`);
```
