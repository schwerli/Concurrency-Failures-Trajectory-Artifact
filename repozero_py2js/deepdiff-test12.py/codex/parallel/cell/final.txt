**Library Files**
[integers.mjs](/output/lib/integers.mjs), [pyrepr.mjs](/output/lib/pyrepr.mjs), [cli.mjs](/output/lib/cli.mjs), [objects.mjs](/output/lib/objects.mjs), and [deepdiff.mjs](/output/lib/deepdiff.mjs) are in `/output/lib`. They split Python-style integer parsing, Python repr rendering, manual `argparse`-compatible CLI handling, object construction, and the minimal DeepDiff-compatible diff logic needed for this script. The CLI display name is intentionally fixed to `test12_executable` so help/error text matches the supplied binary.

**Entry File**
[test12.mjs](/output/test12.mjs) is the `/output` entry point. It is pure Node.js ESM, imports only local `.mjs` files, uses no external dependencies, and prints the 10 diff results with Python-matching formatting.

I verified `node /output/test12.mjs` against `/workspace/dataset/test12_executable` for successful runs and CLI edge cases including help, missing args, invalid ints, unknown args, negative values, underscore-form ints, and repeated flags. In those checks, stdout, stderr, and exit codes matched exactly.
