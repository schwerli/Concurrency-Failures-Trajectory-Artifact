Implemented the Node.js ESM version in `/output` with only local `.mjs` modules.

**Files**
- [cli.mjs](/output/lib/cli.mjs): manual `process.argv` parsing for `--a`, including `argparse`-style help/errors and repeated-arg behavior.
- [index.mjs](/output/lib/index.mjs): library export surface.
- [model.mjs](/output/lib/yaml/model.mjs): internal YAML scalar/type helpers.
- [text.mjs](/output/lib/yaml/text.mjs): low-level text/indent/comment scanning utilities.
- [scalar.mjs](/output/lib/yaml/scalar.mjs): scalar parsing, implicit-type resolution, and scalar formatting rules.
- [parser.mjs](/output/lib/yaml/parser.mjs): YAML loader for block mappings/sequences, flow collections, quoted scalars, and block scalars.
- [dumper.mjs](/output/lib/yaml/dumper.mjs): PyYAML-style dump logic with `explicit_start=True`, sorted mapping keys, indentless sequences, and scalar formatting.
- [test9.mjs](/output/test9.mjs): entry file.
