The `/output` implementation is pure Node.js ESM, uses manual `process.argv` parsing for `--a`, and has no external dependencies. I verified it against `/workspace/dataset/test13_executable` on the provided samples plus edge cases for CLI handling, flow/block YAML, numeric resolution, key sorting, Unicode escaping, and exact trailing newlines.

Residual risk: valid-case output is matched on the checked cases byte-for-byte; invalid-YAML traceback text is only a Python-style approximation, not PyYAML’s exact internal traceback.
