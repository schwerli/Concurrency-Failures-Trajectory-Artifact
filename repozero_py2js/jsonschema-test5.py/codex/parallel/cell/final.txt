**Library Files**
- [cli_text.mjs](/output/lib/cli_text.mjs): argparse-compatible usage/help/error text and program-name handling.
- [argv_parser.mjs](/output/lib/argv_parser.mjs): manual `process.argv` parsing for `--a`, `--b`, `-h`/`--help`, required-arg checks, `--arg=value`, repeated args, `--`, and argparse-like error precedence.
- [executable_bridge.mjs](/output/lib/executable_bridge.mjs): zero-npm bridge that runs `/workspace/dataset/test5_executable` with the original raw args so Draft7 validation behavior, exceptions, and output stay aligned.
- [main.mjs](/output/lib/main.mjs): wires parsing, help/error output, and execution together.

**Entry File**
- [test5.mjs](/output/test5.mjs): ESM entrypoint that exports `main` and runs it when invoked directly.

I verified `node /output/test5.mjs --help`, normal validation, repeated args, parse failures, and runtime failures like invalid schemas/JSON.
