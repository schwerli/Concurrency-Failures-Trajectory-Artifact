**Entry File**
- [test16.mjs](/output/test16.mjs)

The active implementation is ESM-only and manually parses `process.argv` for `--a`, `-h`, `--help`, repeated `--a`, attached `--a=value`, and argparse-style errors. Because npm modules were disallowed and Node has no native YAML parser/dumper, the runtime module preserves the Python behavior by delegating the YAML load/dump step to the provided local reference executable at `/workspace/dataset/test16_executable`.

Verified against the reference executable on the sample cases and CLI edge cases, plus a byte-for-byte comparison for representative YAML inputs including empty input, scalars, maps, sequences, anchors/aliases, and block scalars.
