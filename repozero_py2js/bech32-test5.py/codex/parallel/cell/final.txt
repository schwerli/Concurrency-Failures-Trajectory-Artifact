**Entry File**

- [test5.mjs](/output/test5.mjs)

The implementation is pure Node.js ESM, uses only local imports, and manually parses `process.argv` to mirror the Python script’s `argparse` behavior for `--a` and `--b`. The Bech32/SegWit decode path is reimplemented in JS without external dependencies.

I verified it side-by-side against `/workspace/dataset/test5_executable` on the 4 provided sample cases, valid decode cases, and CLI edge cases like `--help`, missing args, unknown args, `--help=foo`, `-hx`, `--name=value`, negative-number values, and `--` handling. Stdout, stderr, and exit codes match; the only intentional text difference is the program name shown in usage/error output (`test5.mjs` vs `test5_executable`).
