- [orderedMultiDict.mjs](/output/lib/collections/orderedMultiDict.mjs): zero-dependency `OrderedMultiDict`/`OMD` implementation with `add()`, `getlist()`, `keys()`, `items()`, and Python-matching object display for this script.
- [argparseLike.mjs](/output/lib/cli/argparseLike.mjs): manual `process.argv` parser matching the observed `argparse` behavior for `--a`, `--b`, `--c`, help, required-argument errors, `--opt=value`, repeated flags, and error formatting.
- [index.mjs](/output/lib/index.mjs): ESM re-exports.

Entry test file:
- [test6.mjs](/output/test6.mjs): the executable Node entrypoint that reproduces the Python script’s behavior.

Verification: compared the Node version against `/workspace/dataset/test6_executable` for normal execution, help, missing args, unknown args, repeated `--a`, `--opt=value`, negative-number-like values, and quoted/escaped strings.
