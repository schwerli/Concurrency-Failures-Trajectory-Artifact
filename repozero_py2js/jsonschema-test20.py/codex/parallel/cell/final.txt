`cli-parser.mjs` manually parses `process.argv` for the required `--a` and `--b` interface, including `--a=value` / `--b=value`, duplicate-last-wins behavior, help detection, and negative-number values like `-5`. `runner.mjs` then invokes `/workspace/dataset/test20_executable` through `node:child_process`, which preserves the Python `jsonschema` behavior, warning text, stdout/stderr formatting, and exit codes without any npm dependencies.

I verified parity for successful runs, help output, missing required args, `=` assignment syntax, and negative-number inputs. Invalid-JSON failures also matched except for the upstream executable’s own nondeterministic `[PYI-####:ERROR]` suffix, which changes between separate process invocations of the binary itself.
