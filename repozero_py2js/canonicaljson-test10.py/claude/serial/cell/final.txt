The port is complete and verified against the executable: **90/90 targeted cases + 1000 fuzz rounds match** on stdout, stderr, and exit code.

## Key behaviors reverse-engineered from the executable

| Behavior | Finding |
|---|---|
| Output format | `print(bytes)` → Python's `bytes.__repr__`, not the raw JSON |
| Chunk count `20` | CPython's `_iterencode_list` prepends the pending separator to the *next* value (4 chunks for a 3-item list), while `_iterencode_dict` yields key/sep/value separately |
| Canonical encoder | `ensure_ascii=False, allow_nan=False, sort_keys=True, separators=(',',':')` → UTF-8 |
| Float repr | Exponential iff `decpt <= -4 or decpt > 16` (`1e15`→`1000000000000000.0`, `1e16`→`1e+16`) |
| `inf`/`nan` | `ValueError` + traceback + PyInstaller line, rc=1 |
| Arg parsing | `int()`/`float()` accept whitespace, `+`, PEP-515 underscores, and Unicode digits (`int('١٢')==12`); big ints are arbitrary precision |
| `--c -1e5` | Fails — argparse's negative-number matcher is `^-\d+$\|^-\d*\.\d+$` |
| `--` | Classified as `-`, never usable as a value, and still reported as unrecognized |

## Library files

**`/output/lib/errors.mjs`** — Python exception types with a `format()` matching traceback rendering.

**`/output/lib/pytypes.mjs`** — the value model. JS collapses `int`/`float`, so: `str`→string, `int`→**BigInt**, `float`→**`PyFloat`** wrapper, `dict`→`Map`. Also `compareCodePoints`, since JS sorts by UTF-16 code unit and Python by code point.

**`/output/lib/repr/floatrepr.mjs`** — `repr(float)`. Uses `toExponential()` (spec-guaranteed shortest round-trip, same digits as CPython's dtoa), then reformats with Python's decimal-point thresholds.

**`/output/lib/repr/bytesrepr.mjs`** — `bytes.__repr__`: quote selection, `\t`/`\n`/`\r` short forms, `\xHH` for `<0x20` and `>=0x7f`.

**`/output/lib/repr/strrepr.mjs`** — `str.__repr__` for argparse messages. Printability uses CPython's exact category rule via `/[\p{Cc}\p{Cf}\p{Cs}\p{Co}\p{Cn}\p{Zl}\p{Zp}\p{Zs}]/u` with ASCII space carved out — fuzzing caught `U+2028`/`U+E000`/`U+FFFF` before this was correct.

**`/output/lib/codecs/utf8.mjs`** — hand-written encoder so lone surrogates *raise* like Python rather than becoming `U+FFFD`.

**`/output/lib/parse/unicodedigits.mjs`** — `_PyUnicode_TransformDecimalAndSpaceToASCII`, with a 68-entry table of Nd digit-zero code points generated by enumerating `\p{Nd}`.

**`/output/lib/parse/numeric.mjs`** — `int()`/`float()` grammars (`\d(?:_?\d)*` enforces the underscore rule), then `Number()`, which is bit-identical to `strtod`.

**`/output/lib/json/strings.mjs`**, **`/output/lib/json/encoder.mjs`** — escaping and a faithful `JSONEncoder`, preserving `_make_iterencode`'s chunk boundaries.

**`/output/lib/canonicaljson/index.mjs`** — the three public functions.

**`/output/lib/cli/formatter.mjs`**, **`/output/lib/cli/argparse.mjs`** — help layout (help column at `min(len+2+2, 24)` = 14) and two-phase `O`/`A`/`-` classification.

**`/output/lib/sys/stdio.mjs`** — `fs.writeSync` so `process.exit()` can't truncate piped output.

**`/output/lib/sys/traceback.mjs`** — the frozen-executable traceback.

**`/output/test10.mjs`** — the entry point, mirroring the original line for line.

Two notes on deliberate divergences: the usage line shows `test10.mjs` because argparse derives `prog` from `argv[0]` in both runtimes (my harness normalizes this to compare), and argv containing invalid UTF-8 is unreachable — Node replaces the bytes with `U+FFFD` before the script sees them, where Python's `surrogateescape` preserves them and raises. Harnesses are at `/workspace/difftest.mjs` and `/workspace/fuzz.mjs`.
