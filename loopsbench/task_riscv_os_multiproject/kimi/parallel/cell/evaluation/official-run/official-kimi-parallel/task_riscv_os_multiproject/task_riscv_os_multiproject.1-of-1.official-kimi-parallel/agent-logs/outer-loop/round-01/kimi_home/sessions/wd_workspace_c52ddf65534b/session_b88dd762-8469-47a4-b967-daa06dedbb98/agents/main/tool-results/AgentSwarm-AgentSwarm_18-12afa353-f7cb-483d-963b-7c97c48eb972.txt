- `selete_page()` — NRU/second-chance: first pass returns a valid, unpinned page whose PTE `_PAGE_ACCESSED` is clear (clearing the bit on pages it skips), second pass takes any valid unpinned page; asserts if none.
- `write_to_sd(pa)` — allocates a free `disk_page[]` swap slot, writes the page with `sbi_sd_write` (8 sectors at `SWAP_BEGIN + slot*8`), clears `_PAGE_PRESENT` on the owner PTE, stores the slot id in the PTE pfn field, sets `_PAGE_SOFT`, frees the `user_page[]` entry, flushes TLB.
- `init_page_table()` — allocates a pgdir page, copies the shared kernel mapping entry (VPN2 0x101, 2MB large pages) from `PGDIR_PA`, then builds the 3-level SV39 walk for `USER_STACK_ADDR - PAGE_SIZE` and maps a freshly allocated pinned user-stack page (P|R|W|X|U|A|D).
- `free_process_user_page(pgdir)` — walks all 3 levels (skipping shared VPN2 0x101), frees leaf pages (shared-memory pages decrement `shm_page[]` count and are only freed at 0), frees swap slots of `_PAGE_SOFT` PTEs, and releases all page-table pages + pgdir via `free_pgdir_page`.
- `alloc_page_helper(va, pgdir)` — builds missing second/last-level tables on demand, maps a freshly allocated unpinned user page at the leaf (P|R|W|X|U|A|D), returns `get_kva_of(va, pgdir)` (used by `load_elf`).
- `shm_page_get(key)` — allocates the shared physical page on first use (pinned, zeroed), bumps the refcount, maps it into the current pgdir at `0x1000 + key*PAGE_SIZE` (the documented share region), returns that va.
- `shm_page_dt(addr)` — clears the leaf PTE in the current pgdir, decrements the refcount, frees the physical page at 0.
- `handle_page_fault(regs, stval, cause)` — walks the current pgdir; unmapped levels/leaves → demand paging via `alloc_page_helper` (needed by `test_large` touching va 0x20000); `_PAGE_SOFT` leaf → allocates a page, `sbi_sd_read`s the swap slot back, frees the disk slot, restores full attributes and `_PAGE_PRESENT`.
