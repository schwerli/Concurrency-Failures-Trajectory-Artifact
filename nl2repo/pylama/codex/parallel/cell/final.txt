Implemented a complete `pylama` project from scratch in [setup.py](/workspace/setup.py), [pylama/__init__.py](/workspace/pylama/__init__.py), [pylama/config.py](/workspace/pylama/config.py), [pylama/main.py](/workspace/pylama/main.py), and the linter adapters under [pylama/lint/__init__.py](/workspace/pylama/lint/__init__.py). It includes the unified public API, INI/TOML config loading, recursive path scanning, sync and async execution, error formatting/deduplication, git and Mercurial hooks, pytest integration, bundled `inirama`, and wrappers for `pycodestyle`, `pyflakes`, `mccabe`, `pydocstyle`, `pylint`, `mypy`, `isort`, `eradicate`, `radon`, and `vulture`.

Verified locally with `python -m compileall /workspace`, editable install via `python -m pip install -e /workspace`, `pylama --version`, and smoke tests for `parse_options`, `get_config`, `check_paths`, `run`, `check_async`, stdin mode, TOML discovery, and duplicate-error handling. The prompt’s official `submit` tool is not available in this environment, so I could not run the hidden suite from here.
