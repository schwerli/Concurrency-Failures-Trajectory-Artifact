Implemented the project as an installable `pandarallel` package. Local verification passed for `DataFrame.parallel_apply`, `parallel_applymap`, `Series.parallel_apply`, `parallel_map`, grouped `parallel_apply`, rolling, grouped rolling, grouped expanding, plain expanding API surface, memory-fs selection, `MEMORY_FS_ROOT` env override, exception propagation, and `python setup.py --name --version`.
