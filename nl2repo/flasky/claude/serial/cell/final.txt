## Two judgment calls worth knowing about

1. **The spec is internally inconsistent in Node 4**: it mandates `self.follow(self)` in `User.__init__`, which necessarily makes `len(user1.followed.all())` equal `2` after following one user, not the `1` the comment claims. I followed the authoritative class definition (self-follows), which is also what the reference project's own `test_follows` asserts.
2. **Node 5's example expects `201` when creating a post without ever calling `insert_roles()`** — a user would otherwise have no role and no `WRITE` permission. I made the default roles part of the schema via an `after_create` hook on the roles table, so `db.create_all()` yields them; `insert_roles()` stays idempotent for migration-based deploys.
