Implemented the Stamina package as an installable `src`-layout project in [pyproject.toml](/workspace/pyproject.toml), with the public API surfaced from [src/stamina/__init__.py](/workspace/src/stamina/__init__.py). The core retry behavior lives in [src/stamina/_core.py](/workspace/src/stamina/_core.py): Tenacity-backed retry decorator, sync/async retry contexts, caller classes, exponential backoff with jitter, asyncio/Trio-compatible async sleep, stop-condition composition, and backoff helpers. Global activation and test-mode controls are in [src/stamina/_config.py](/workspace/src/stamina/_config.py), and observability hooks are implemented in [src/stamina/instrumentation/__init__.py](/workspace/src/stamina/instrumentation/__init__.py) plus the instrumentation submodules.

I also added docs and examples in [README.md](/workspace/README.md) and [examples/http_retry.py](/workspace/examples/http_retry.py), [examples/database_retry.py](/workspace/examples/database_retry.py), [examples/api_retry.py](/workspace/examples/api_retry.py), along with a local test suite in [tests/test_stamina.py](/workspace/tests/test_stamina.py). Verification: `python -m pip install -e '.[test]'` succeeded and `pytest -q` passed with `17 passed`. The requested `submit` tool is not available in this environment, so I couldn’t run the official external suite.
