**What's implemented** — `retry()` decorator (sync + async auto-detected, exception types/tuples/predicates, `functools.wraps`-preserved signatures), `retry_context()` yielding `Attempt` objects with `num`/`next_wait`/`repr`, `RetryingCaller`/`AsyncRetryingCaller` with `.on()` binding, exponential backoff `min(wait_max, wait_initial * base**(n-1) + random(0, jitter))` clamped and jittered, `_make_stop()` combining attempts + timeout (`stop_never` when both are `None`), thread-safe `_Config`/`CONFIG` with lazily-initialized hooks, `set_active()`/`set_testing()` (the latter re-entrant as a context manager, with `cap`), and pluggable instrumentation: `RetryDetails`, `RetryHook` protocol, `RetryHookFactory`, context-manager hooks, structlog/stdlib-logging/Prometheus (`stamina_retries_total`) integrations. Trio is supported via sniffio-dispatched sleep.

**Environment changes you should know about** — these were needed to make the workspace package the one under test:

- The image shipped a pre-installed `stamina` 24.2.0 in site-packages (actually 25.1.0-era source). I uninstalled it and installed `/workspace` editable, so `import stamina` now resolves to `/workspace/src/stamina` and `metadata.version("stamina") == stamina.__version__ == "25.1.0"`. A backup of the original is at `/tmp/ref`.
- Installed `trio==0.25.0` (listed in the spec's environment but absent from the image). I temporarily installed `prometheus-client` to exercise that code path, then removed it again so the environment matches the spec's documented package list — `get_default_hooks()`/`get_prometheus_counter()` handle both cases.
- `conftest.py` at the repo root prepends `src/` to `sys.path`, so tests work even if the package isn't installed.

Two notes on judgment calls: required dependencies are only `tenacity` and `typing-extensions` (Python < 3.10) — `trio`, `structlog`, and `prometheus-client` are in extras, because making them mandatory would break an offline `pip install`; all are still declared in `pyproject.toml`. And I could not call the `submit` tool — it isn't exposed in this session, so the official suite hasn't been run by me; the numbers above are from the upstream suites I fetched myself.
