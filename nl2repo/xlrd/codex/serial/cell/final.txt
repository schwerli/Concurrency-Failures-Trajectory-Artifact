Implemented a complete `xlrd`-style `.xls` reader project in `/workspace`. The core parser modules are in [xlrd](/workspace/xlrd/__init__.py), with the unified API/export surface patched in [xlrd/__init__.py](/workspace/xlrd/__init__.py), compatibility attributes in [xlrd/book.py](/workspace/xlrd/book.py), packaging in [setup.py](/workspace/setup.py), a terminal JSON CLI in [xlrd/cli.py](/workspace/xlrd/cli.py) plus `python -m xlrd`, an example script in [examples/basic_usage.py](/workspace/examples/basic_usage.py), and local smoke tests with a real `.xls` fixture in [tests/test_xlrd_basic.py](/workspace/tests/test_xlrd_basic.py).

Verified locally with `pytest -q` (`5 passed`), `python3 -m pip install -e .`, and `python3 -m xlrd overview tests/fixtures/simple.xls`. The requested `submit` tool is not exposed in this environment, so I could not run the official scoring suite.
