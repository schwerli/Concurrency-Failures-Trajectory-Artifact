## Three real bugs I found and fixed

1. **`scripts/runxlrd.py` was entirely broken** — it referenced `xlrd.USE_MMAP`, which no longer exists in 2.x, so *every* documented CLI invocation (`ov`, `3rows`, …) died on `AttributeError`. Restored `USE_MMAP` in the package.
2. **Four documented `Book` attributes were missing** (`filename`, `file_contents`, `_data`, `_sheets`). I added them as live aliases over `filestr`/`_sheet_list` rather than copies, so they can't drift and don't defeat `release_resources()`'s memory management. Note `file_contents` is `None` after a normal load — that's `release_resources` freeing the buffer, and it's only non-`None` under `on_demand=True`.
3. **`MANIFEST.in` shipped a nonexistent `README.md`**; corrected to `README.rst` and extended so sdists actually contain the tests and samples.

## Two spec points worth flagging

- **`hex_char_dump` conflicts with the spec.** The spec says non-printables render as `.`; the implementation renders NUL as `~` and others as `?`. I kept the existing behavior because `tests/test_biffh.py` asserts `"abc~e?"` — changing it to match the prose would fail that test. Flagging in case the prose is what you actually want.
- **`install_requires` is intentionally empty.** The spec asks for pinned deps like `coverage==7.2.7`, but those are test-only — this library is pure stdlib. Pinning them as install requirements would make `pip install` fail in any environment lacking them. They're declared in `extras_require['test']` and `requirements.txt` instead (`pip install -e .[test]`).
